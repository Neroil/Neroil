### 🎓 Bachelor Thesis — Smith Chart Tool

Built a **modern, cross-platform Smith chart application** for RF impedance matching — designed to actually show you what's happening step by step, unlike black-box simulators.

Key features:
- Manual impedance matching with passive components (R, L, C, transmission lines, stubs)
- Real-time trajectory visualization on the Smith chart + live circuit schematic
- S1P / Touchstone file import & export, multi-band frequency highlighting
- Frequency sweep analysis with exportable results
- IEC 60063 normalized component catalog, quality factor support, undo/redo, project save
